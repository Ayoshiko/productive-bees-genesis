# 核心机器

本模组只有两台核心机器：机械蜂箱负责养蜜蜂产蜜脾，通用机械离心机负责把蜜脾拆成资源。先看懂它们，后面的升级和自动化才有意义。

本章包含两页，两台机器的界面**分开讲**，不混在一起：

- [机械蜂箱](apiary.md)：蜜蜂槽与蜂笼槽、蜜蜂提示、输出分页、**喂食槽窗口**（转化开关、逐格禁用、翻页、统计面板）、蜂箱侧的 PB 升级、直连离心机与产物去向。
- [通用机械离心机](centrifuge.md)：输入/输出槽、流体罐、**输入返还按钮**、**多流体槽窗口**、熔炼兼容、直连输出、**AE2 输入入口**、离心机侧的 PB 升级。

两台机器通用的部分（能量、进度、红石、安全、侧面配置与自动弹出）统一写在[界面总览与公共操作](../gui.md)。
