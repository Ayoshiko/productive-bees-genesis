# 资源蜜蜂：创世

<ItemImage id="productivebeesgenesis:mek_apiary" scale="2" />

这本书从"完全没玩过科技模组"开始讲。你不需要先懂 FE、管道或 AE2：先照着入门章节搭出第一条生产线，看到蜜脾变成资源后，再按需要学习升级和自动化。

## 怎么用这本书

**全部页面都在左侧导航栏里**：四个章节是顶层，点一下章节名就会展开它下面的子页。

想按问题查而不是按顺序读，看下面的"按问题找答案"，或者用书内的搜索。

## 按问题找答案

- 想知道万象创世蜜蜂是什么：[万象创世蜜蜂](myriad.md)
- 不知道某个按钮是干什么的：[界面总览与公共操作](gui.md)，再看对应机器的页面
- 想知道蜂箱的喂食槽和 PB 升级怎么用：[机械蜂箱](machines/apiary.md)
- 想知道离心机的多流体槽、熔炼兼容、输入返还和直连输出：[通用机械离心机](machines/centrifuge.md)
- 想知道升级能装几个、蜂箱和离心机各支持什么：[PB 升级窗口详解](upgrades/pb-upgrades.md)
- 想限制机器从 AE2 拿什么：[AE2 输入窗口详解](upgrades/ae2-input.md)与[过滤器](filter.md)
- 想调整产量、耗电或特效：[配置](configuration.md)
- 机器不动、没产物或网络掉线：[故障排查](troubleshooting.md)
