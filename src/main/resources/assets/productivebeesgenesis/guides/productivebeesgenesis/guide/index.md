# 资源蜜蜂：创世

这本书从“完全没玩过科技模组”开始讲。你不需要先懂 FE、管道或 AE2：先照着入门章节搭出第一条生产线，看到蜜脾变成资源后，再按需要学习升级和自动化。

## 先走这条路

1. [第一次开机](getting_started/index.md)：认识 FE、机器界面和最小生产线。
2. [机械蜂箱](machines/apiary.md)：让蜜蜂在机器里稳定产出。
3. [通用机械离心机](machines/centrifuge.md)：把蜜脾拆成真正能用的资源。
4. [升级与自动化详解](upgrades/automation.md)：生产稳定后，再追求更快、更省事。

## 按问题找答案

- 想知道万象创世蜜蜂是什么：[万象创世蜜蜂](myriad.md)
- 看不懂按钮和侧面颜色：[界面与按钮](gui.md)
- 想限制机器从 AE2 拿什么：[过滤器](filter.md)
- 想调整产量、耗电或特效：[配置](configuration.md)
- 机器不动、没产物或网络掉线：[故障排查](troubleshooting.md)
