# PB 升级窗口详解

![资源蜜蜂升级窗口](../assets/images/gui_pb_upgrades.png)

**PB 升级**是把 Productive Bees 的升级装进 Mekanism 机器里的窗口。机械蜂箱和通用机械离心机共用同一个窗口，但**两台机器支持的升级不完全一样**，所以本页把窗口用法和两台机器的差异分开讲。

## 先分清两套升级

每台机器上其实有**两个**升级入口，装的是两套不同的东西：

| | PB 升级（本页） | MEK 升级 |
| --- | --- | --- |
| 标签颜色 | 橙色 | Mekanism 默认色 |
| 图标 | 本模组自绘的升级图标 | 向上箭头 |
| 装什么 | Productive Bees 与资源蜜蜂：创世的升级 | Mekanism 原版升级 |
| 典型物品 | 产量 α/β/γ/Ω、速度、速度+、稳定性、基因采样器、两种基因插件、蜜脾块、粗矿熔炼、精华转化、副产物销毁 | 速度升级、能量升级、消音升级；装扩展后还有堆叠升级、创造升级 |
| 典型效果 | 提高每轮产量、缩短生产时间、改变产物形态 | 缩短每轮时间、扩大能量缓存、降低噪音 |

两套可以**同时安装、效果叠加**，互相不占用对方的槽位。

## 怎么打开

点机器窗口右侧的橙色 **PB 升级**标签（悬停显示"资源蜜蜂升级"）。窗口会在主界面上居中弹出，标题写着"资源蜜蜂升级"。

## 窗口结构

窗口分成四个区域：

- **标题栏**：最上方，左边是关闭按钮与图钉，中间写着"资源蜜蜂升级"，拖动可以移动窗口。
- **左上：已安装升级列表**：只列已经装上的升级，每种一行；装不下时右侧出现滚动条。
- **右上：升级信息屏**：显示选中升级的名称、数量与说明。
- **下半部分**：左边是这台机器支持的升级种类，右边是安装进度条、卸载按钮与输入/输出槽。

### 标题栏

- 左上角的 **×** 关闭窗口，里面的升级已经装好，不会因为关窗口而失效。
- **图钉**：钉住窗口，主界面移动时不再跟随。
- 拖动标题栏可以移动窗口，位置会被记住（见[界面总览与公共操作](../gui.md)的"窗口跑到屏幕外"）。

### 左上：已安装升级列表

这一栏只列出**已经装上的**升级，每种一行：

- 每行左边是升级物品的小图标，右边是升级名字。
- 行底色是**该升级类型的专属颜色**，一眼能分辨等级。
- **鼠标悬停**一行：显示"升级名（同色）+ 效果说明"。
- **左键点一行 = 选中**：该行会切换成"选中"样式，右下角的**卸载按钮随之亮起**。没选中任何行时，卸载按钮是灰的、点不动。
- **点列表的空白处 = 取消选中**。
- 升级多到装不下时，列表**最右侧会出现一条滚动条**：可以**滚动鼠标滚轮**，也可以**按住 4×4 的小滑块拖动**。
- 如果选中的那种升级被卸载到 0 个，选中状态会**自动取消**，信息屏恢复成"未选择"。

### 右上：升级信息屏

选中某一行之后，这里显示三行内容：

1. **升级名称**（用该类型的颜色，过长会自动换行）
2. **`已装数量 / 上限`**，例如 `3 / 8`
3. **效果说明**，例如"提升蜜脾产出数量"

什么都没选时，这里显示 **未选择**。

### 右下偏上：安装进度条

把升级物品放进**输入槽**（信息屏右侧偏上的那个格子）后，这里会出现一段短暂的**安装进度动画**，走完即安装成功，物品从输入槽消失、已装数量 +1。

### 右下：卸载按钮

- 按钮上写着 **卸载**，悬停提示是 **"卸载选中升级（Shift+点击卸载全部）"**。
- **左键 = 卸载 1 个**：从机器里取出一个该类型的升级，放到下面的**输出槽**里。
- **Shift + 左键 = 卸载全部**：把该类型已装的数量一次全部取出。
- 没有选中任何升级时按钮灰显、点不动。
- 卸载出来的物品出现在**输出槽**（卸载按钮正下方那个格子），别忘了取走。

> 卸载是**瞬时**的，没有进度动画——不要以为没反应就是失败了，先看输出槽里有没有东西。

### 左下：支持列表

标题是 **支持：**，后面跟着一排 **12×12 的小图标**，代表**这台机器能装哪些升级**。

- 图标悬停显示"升级名（该类型颜色）+ 效果说明"。
- **灰罩 = 不支持**：图标上盖了一层半透明灰，悬停时名字会变成红色的 **"XXX（不支持）"**，下面仍然显示效果说明。
- 判断"能不能装"就靠这一行。两台机器的支持列表不同，见下文对照表。
- 蜂箱还会在这里看到 **模拟 ✓**——它是**内置**的，不用装也不占槽位。

## 蜂箱与离心机：支持的升级对照表

这是两台机器**最容易搞混**的地方。同一个 PB 升级窗口，蜂箱和离心机认的东西不一样：

**两边都能装的**

- **产量 α / β / γ / ω**：提高每轮蜜脾产出数量（PB 默认系数 1.2 / 1.5 / 2.0 / 2.6），其中 ω **自带蜜脾块模式**。
- **速度 / 速度+**：每级减少 **15%** / **30%** 生产时间，耗电随之上升。
- **副产物销毁**：蜂箱清理蜂蜜类副产物与花粉球；离心机清理 PB 蜂蜜流体与蜜蜡。**主要产物不受影响**。
- **精华转化**：把"能用单一材料逆向合成"的低级产物自动压缩成更省地方的形态。

**只有蜂箱能装的**

- **基因采样器**：采样蜜蜂基因。
- **基因种类筛选**：基因采样器只产出蜜蜂种类（TYPE）基因；每台蜂箱最多一个。
- **基因满纯度**：基因采样器产出的每份基因都直接达到 100% 纯度；每台蜂箱最多一个。
- **蜜脾块**：把蜜脾产出改成输出蜜脾块，省输出格。
- **模拟**：蜂箱出厂自带，不占槽位、不用安装。

两种基因插件都要配合**基因采样器**才有效，也可以同时安装：组合后只产出 100% 纯度的蜜蜂种类基因。插件各自最多安装 1 个，不占用基因采样器的数量上限。

**只有离心机能装的**

- **稳定性**：每级 **+15%** 非保底产物概率。
- **粗矿熔炼**：把离心出来的粗矿按熔炼配方直接变成金属锭。

装错机器时，那个图标在支持列表里就是**灰的**，把物品放进输入槽也不会被安装。

## 能装多少个

每种升级有各自的**上限**，上限由**服务器配置**决定，而且**蜂箱和离心机各自一套**：

| 升级 | 默认上限 | 对应配置项 |
| --- | --- | --- |
| 产量 α / β / γ / Ω | 8（四种各自独立计数） | `产量升级上限` |
| 速度、速度+ | 8（两种各自独立计数） | `时间升级上限` |
| 稳定性（仅离心机） | 7 | `稳定性升级上限` |
| 基因采样器（仅蜂箱） | 4 | `基因采样升级上限` |
| 基因种类筛选、基因满纯度（仅蜂箱） | 1（两种各自独立） | — |
| 蜜脾块（仅蜂箱） | 1 | `蜜脾块升级上限` |
| 副产物销毁 / 精华转化 / 粗矿熔炼 | 1（功能型，装一个即满） | — |
| 模拟 | 蜂箱内置 | — |

配置项分成两组：**机器设置 → 通用机械蜂箱 → PB 升级上限** 和 **机器设置 → 通用机械离心机 → PB 升级上限**。改之前先想清楚是哪一台机器。

上限的默认值还会**受全局平衡模式影响**，见下一节。

## 平衡模式：基础 / 悖论无限 / 自定义

在**模组配置 → 玩法设置 → 平衡性规则**里可以切换全局平衡模式（点"全局平衡性配置"打开模式列表）：

- **基础**：更接近 Mekanism 与 Productive Bees 原本的样子。**产量升级 α/β/γ/Ω 互斥**，**速度 I 与速度 II 互斥**；离心机的产量升级**只增加并行、不增加产量**；蜂箱会受蜜蜂的**行为与天气耐受基因**影响；资源蜜蜂升级默认上限 **4**，离心机堆叠升级默认上限 **8**。
- **悖论无限**：产量升级的各等级**可以共存**，速度 I 与速度 II **可以共存**；离心机产量升级**同时增加产量和并行**；蜂箱沿用旧版本行为，**不受**蜜蜂行为与天气耐受基因影响；资源蜜蜂升级默认上限 **8**，离心机堆叠升级默认上限 **16**。
- **自定义**：下面每一项独立规则和数量上限都自己填。从"基础"或"悖论无限"切过来时，会**继承切换前实际生效的设置**。

> **切换模式不会移除机器里已经装好的升级。** 但它可能**阻止你继续装入不符合新规则的升级**——例如从"悖论无限"切到"基础"之后，同一台机器上就不能再混装不同等级的产量升级了，已经装上去的原样保留。

自定义模式下的四项独立规则（悬停原文）：

- **产量升级等级互斥**：禁止产量升级 α、β、γ、Ω 在同一台机器中共存。
- **速度升级等级互斥**：禁止速度 I 与速度 II 两种速度升级在同一台机器中共存。
- **离心机产量升级增加产量**：开启后同时增加产量与并行；关闭后仅保留资源蜜蜂原版并行能力。
- **蜜蜂基因影响蜂箱工作**：蜜蜂的行为或天气耐受基因不适应当前昼夜与天气时，暂停该蜜蜂的生产。

## 常见问题

- **升级放进去没反应**：先看左下"支持："列表里那个图标是不是**灰的**。灰的就是这台机器不支持它。
- **数量停在 `8 / 8` 装不进去**：到上限了。要么卸载一些，要么去服务器配置里调高对应上限。
- **卸载按钮点不动**：没选中任何升级。先在左上列表里点一行。
- **卸载了但东西不见了**：去**卸载按钮下方的输出槽**取。
- **产量升级装不上第二种等级**：当前是"基础"平衡模式，产量等级互斥。切到"悖论无限"或改用"自定义"。
- **蜂箱里的蜜蜂突然不产了**：当前是"基础"模式时，蜜蜂的行为 / 天气耐受基因会影响产出，检查昼夜与天气，或者切到"悖论无限"。
- **关掉窗口后升级还在吗**：在。升级装在机器里，和窗口是否打开无关。
- **换机器（升级工厂）会丢升级吗**：工厂升级会保留里面的蜜蜂和已装升级。
