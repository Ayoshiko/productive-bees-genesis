# Productive Bees Genesis

This guide starts from a player's first powered machine. Follow the quick-start path to turn a bee's comb into a useful resource, then add factories, upgrades, and AE2 automation only after the basic line works.

## Recommended path

1. [First startup](getting_started/index.md): learn FE, machine screens, and the smallest working line.
2. [Mekanism Apiary](machines/apiary.md): produce combs reliably.
3. [Mekanism Centrifuge](machines/centrifuge.md): turn combs into resources.
4. [Upgrades and Automation](upgrades/automation.md): scale only after outputs are stable.
