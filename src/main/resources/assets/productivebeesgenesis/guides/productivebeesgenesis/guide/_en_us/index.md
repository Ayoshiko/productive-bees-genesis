# Productive Bees Genesis

<ItemImage id="productivebeesgenesis:mek_apiary" scale="2" />

This guide starts from a player's first powered machine. Follow the quick-start path to turn a bee's comb into a useful resource, then add factories, upgrades, and AE2 automation only after the basic line works.

## How to use this book

**Every page lives in the left navigation**: the four chapters sit at the top level — click a chapter name to expand its sub-pages.

To look something up by symptom instead of reading in order, use "Find an answer" below or the in-book search.

## Find an answer

- What is the Myriad Creations bee: [Myriad Creations Bee](myriad.md)
- What does this button do: [Common Screens and Controls](gui.md), then that machine's page
- How do the apiary Feeder and PB Upgrades work: [Mekanism Apiary](machines/apiary.md)
- How do multi-fluid tanks, smelting compatibility and direct output work: [Mekanism Centrifuge](machines/centrifuge.md)
- How do I limit what a machine pulls from AE2: [AE2 Input Window](upgrades/ae2-input.md) and [Filters](filter.md)
- Tune yield, power, or effects: [Configuration](configuration.md)
- Machine stalled, no products, or network offline: [Troubleshooting](troubleshooting.md)

> Tip: hover any item icon in this guide to read its name. Recipes and block models come from the running game, so modpack recipe changes are reflected automatically.
