# 界面总览与公共操作

<ItemImage id="mekanism:configurator" scale="2" />

这一页只讲**所有机器都一样**的部分：窗口框架、能量条、进度条、红石控制、安全、侧面配置和自动弹出。

机械蜂箱和通用机械离心机各自的槽位、标签和弹窗，分别写在[机械蜂箱](machines/apiary.md)与[通用机械离心机](machines/centrifuge.md)里，不再堆在同一页。

## 窗口的五个部分

打开任意一台机器，窗口都能分成五块：

1. **标题栏**：最上方居中，写着机器名称，例如"通用机械蜂箱""通用机械离心机"。标题栏左边是关闭按钮和**图钉**（钉住窗口），拖动标题栏可以移动窗口。
2. **左侧标签栏**：贴在窗口左边缘的小凸起，自上而下排列。机器自己的输入输出入口大多在这里。
3. **右侧标签栏**：贴在窗口右边缘，放升级、红石与安全。有异常时最上面会多出一个**警告标签**。
4. **中间主体**：能量条、流体罐、进度条、输入槽与输出槽。每台机器不同，见各自页面。
5. **底部**：玩家物品栏，标题写着"物品栏"。按住 Shift 点击可以整组快速搬运。

> 标签的图标不一定看得出含义，**把鼠标停上去就会显示中文名称**。所有槽位、按钮、进度条也都支持悬停提示，遇到不认识的元素先悬停。

## 能量条与 FE 标签

- **能量条**是一根竖条，指针高度代表当前存了多少 FE。悬停可以看到"当前 / 上限"的具体数字。
- 一直贴着 0：没接电，或者接电的那一面没有设成能量输入。
- 忽高忽低：供电不稳，机器会反复启停，产量自然上不去。
- **FE 标签**是能量信息页：当前 FE、容量、每 tick 消耗量。装了 Applied Flux 时这里还会显示网络供电状态，详见[升级与自动化详解](upgrades/automation.md)。

## 进度条

进度条（箭头或横条）显示本轮工作完成了多少。悬停可以看到正在处理什么、还缺什么。常见提示：

- **输入不匹配**：放进去的东西这台机器没有对应配方。
- **输出已满**：产物没地方放，机器会停下来等你腾出空间，不会吞掉输入。
- **能量不足**：供电跟不上。

## 红石控制

**红石控制**标签决定机器在什么条件下工作。点一下换下一档，四种模式循环：

| 档位 | 含义 |
| --- | --- |
| 红石检测：忽略 | 默认。有没有红石信号都照常工作，新手保持这一档 |
| 红石检测：高 | 收到红石信号才工作 |
| 红石检测：低 | 没有红石信号时才工作（信号反相） |
| 红石检测：脉冲 | 收到红石脉冲时工作一次 |

设成"高"或"低"之后忘了接红石，是"机器明明有电却不动"最常见的原因。

## 安全

**安全**标签控制其他玩家能不能打开或修改这台机器。单人游戏不用管；多人服务器上自动化突然失效、别人打不开你的机器时，先回来看这里的权限设置。

## 侧面配置

**侧面配置**是整台机器的"接线说明书"：它决定机器的六个面各自允许进什么、出什么。接了管道没反应，第一个要检查的就是这里。

### 怎么打开

机器窗口**左侧最上方的标签**（方块/九宫格图标）就是**侧面配置**。点击后弹出一个 156×135 的侧面配置窗口。

### 窗口里有什么

- **传输类型标签**（窗口顶部一排）：切换现在要配置哪一类内容——**物品 / 流体 / 能量 / 热量 / 化学品**。每台机器只显示它自己支持的几种。
- **中间的六个面按钮**：按立方体展开图排列，分别是上、前、左、右、底、后。每个按钮上直接写着该面当前的状态。
- **信息屏**（窗口中间偏上的一小条）：显示当前选中的类型名称。
- **自动弹出按钮**（右上角 14×14）：见下文。
- **清空按钮**（右下角 14×14）：把当前类型的六个面一次性恢复成"无"。按住 Shift 点击则是清空**全部**类型。

> **每种传输类型各记一套设置。** 改物品的方向不会影响流体，改流体也不会影响能量，所以换标签之后要重新看一眼六个面。

### 四种面状态

每个面有四种状态，**左键点一下换下一档，按住 Shift 点则退回上一档**：

| 状态 | 含义 |
| --- | --- |
| **无** | 这个面完全封闭，什么都不许通过。防止管道误插就靠它 |
| **输入** | 只允许外部把内容送进机器 |
| **输出** | 只允许机器把内容送出去 |
| **输入/输出** | 双向都允许，适合接 ME 网络这种双向通道 |

按钮颜色只是给眼睛的提示（不同资源包可能有差异），**真正有效的是按钮上的文字**。不确定的时候以文字为准。

> **重要：只把一面设成"输出"并不会让机器主动推送。** 面状态只回答"允不允许往这边走"；"要不要主动送"由**自动弹出**、管道抽取，或者本模组自己的直连按钮决定。

### 自动弹出

侧面配置**右上角的 14×14 按钮**是 Mekanism 的**自动弹出**开关，只对当前选中的类型生效：

- 打开后，机器会主动把这一类型的内容推向设为"输出"的相邻容器或管道。
- 关掉它，即使面设成"输出"，也只能等管道来抽或者你自己取。
- 弹出的速率与"过量百分比"由 Mekanism 自己的配置控制，不在本模组的配置里。

## 本模组在侧面配置里注入的按钮

本模组把常用开关直接做进了侧面配置窗口，不用来回翻标签。它们长得都一样：

> **14×14 的灰色小方块，中间一个字母；功能开启时字母变成绿色，关闭时是深灰色。** 鼠标悬停会显示完整说明。

位置固定在窗口内的两列：**左列 x=120，右列 x=136**。绝大多数只在**物品**页出现；`A`（输出到 AE）在物品页和流体页都会出现。

### 机械蜂箱

- **`A` 输出到 AE**（左列上）：开关这台蜂箱向 ME 网络推送产物。物品页管物品，流体页管流体；没装 AE2 时不显示。
- **`M` 产物直入 AE**（左列中）：新产物直接尝试进 ME 网络，不再经过本地输出槽。只有已经打开 `A` 的某一页才可点。
- **`O` 产物直通相邻容器**（左列下）：新产物先模拟，再写进侧面配置里设为"物品输出"的相邻容器；塞不下的部分回落输出槽。受服务器总开关限制。
- **自动弹出**（右列上，Mekanism 原生）：见上文。
- **`D` 离心机特殊直连**（右列中）：产物直接塞进相邻离心机，不经输出槽。用物品输出面指定直连哪几台（可以多台）。
- **`P` 离心机优先**（右列下）：蜜脾产出后优先送给离心机；离心机满时先暂存在蜂箱缓存里，超出上限才转给 AE。没装 AE2 时不显示。

### 通用机械离心机

- **`A` 输出到 AE**（左列上）：同蜂箱。
- **`I` AE2 输入配置**（左列第 2 格）：打开 [AE2 输入窗口](upgrades/ae2-input.md)，让离心机主动从 ME 网络拿料。仅物品页显示，没装 AE2 时不显示。
- **`F` 兼容电力熔炼炉配方**（左列第 3 格）：让这台离心机顺手处理可熔炼输入。需要服务器总开关先打开。
- **`A` 新产物直入 AE**（左列第 4 格）：新产物跳过本地缓存直接进网络，网络拒收的部分回落本地输出。
- **`O` 产物直通相邻容器**（左列第 5 格）：同蜂箱。
- **自动弹出**（右列上，Mekanism 原生）：见上文。

## 窗口跑到屏幕外

**喂食槽、多流体槽、PB 升级、AE2 输入**这几个窗口会记住上次的位置和"钉住"状态。改了分辨率或 GUI 缩放之后如果窗口看不见了：

1. 打开模组配置（模组列表 → 资源蜜蜂：创世 → 配置）。
2. 进入**客户端设置 → 自定义窗口位置**。
3. 找到对应窗口（`window_feeder` / `window_pb_upgrade` / `window_ae_input` / `window_multi_fluid_tanks`），重置它的坐标。

不必删除整个配置文件。

## 操作速查

| 操作 | 效果 |
| --- | --- |
| 左键拖物品 | 放下整组 |
| 右键拖物品 | 放下一个 |
| Shift + 左键物品 | 整组快速搬运（机器 ↔ 背包） |
| Shift + 左键侧面按钮 | 反向切换状态 |
| 左键点标签 | 打开或关闭对应窗口 |
| 拖动标题栏 | 移动窗口 |
| 点标题栏左侧图钉 | 钉住窗口，主界面移动时不再跟随 |
| 悬停任意元素 | 显示名称与状态说明 |
