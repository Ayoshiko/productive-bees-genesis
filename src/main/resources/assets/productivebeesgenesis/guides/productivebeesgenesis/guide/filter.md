# 过滤器

<ItemImage id="minecraft:hopper" scale="2" />

过滤器就是一张“允许处理什么”的清单。本模组有两种常见用途：限制万象创世可能选中的蜜蜂，以及限制离心机从 AE2 网络主动拉取的物品。

## 三种模式

- **关闭过滤**：不看名单，所有符合其他条件的内容都可通过。
- **黑名单**：名单里的拒绝，名单外的允许。适合只排除少数东西。
- **白名单**：只允许名单里的。适合严格控制自动化，但空白名单会让所有内容都无法通过。

## 万象创世蜜蜂名单

在模组配置的**玩法设置 → 万象创世过滤**中打开编辑器。可以按玩家看到的名称搜索蜜蜂，选中后添加；拖动左侧手柄调整顺序，取消勾选可暂时停用而不删除。

工具栏支持全选、删除、恢复默认、导入和导出。导入完成后必须点**保存**才会生效；某一行写错只会标记该行，不会清空已有名单。

普通玩家优先使用搜索与选择界面。`模组名:蜜蜂名` 这种注册 ID 主要用于整合包作者批量导入。

在离心机的 AE2 输入窗口中：

1. 先选择白名单。
2. 添加一种蜜脾作为测试。
3. 开启精确匹配，保证不同蜜蜂类型不会被当成同一种空白蜜脾。
4. 把单次拉取量设小，并给网络设置保留量。
5. 确认离心机能正常处理、输出也能回网后，再逐步增加条目。

## 熔炼输入表达式

高级用户可使用标签和通配表达式筛选熔炼输入：

- `&` 表示“同时满足”；`|` 表示“满足任意一个”；`^` 表示“只有一边满足”。
- `!` 表示排除；括号用于明确先后关系。
- `*` 可匹配任意一段名称。
- `#c:ores & !#c:ores/iron` 表示“矿石标签中排除铁矿”。
- `minecraft:*_ore` 表示“原版命名空间下以 `_ore` 结尾的物品”。

这不是新手必需功能。表达式写错时，该候选会被拒绝，但其他有效条目仍会继续工作；先从一条短规则开始，确认结果后再组合。
